# GChat

Закрытое приложение для голосовых интернет-звонков один на один. Первая клиентская платформа — нативная iOS; сервер находится в pnpm-монорепозитории.

- [Документация по задачам](docs/README.md).
- [Разработка и workspace](docs/development.md).
- [Запуск backend](applications/backend/README.md).
- [Системные E2E GChat](tests/e2e/README.md).
- [iOS](applications/ios/README.md).
- [Правила для агентов](AGENTS.md).

Существующие корневые Compose и setup.sh относятся к Mattermost/Jitsi. Их пользовательская инструкция вынесена в [legacy](docs/legacy/mattermost.md); новая звонилка имеет собственные аккаунты.
