# Шаблон контракта модуля

Копируйте структуру в `modules/<name>.md` или `modules/<name>/README.md`, если контракт и записи решений хранятся вместе. Заполняйте разделы применительно к модулю. Формат соседних записей решений описан в [правилах документации](../README.md#поддержка-документации). Не выдумывайте открытых решений, если их нет. Численные настройки не дублируйте в обзорных файлах.

```yaml
---
doc_type: module
decision_status: draft
implementation_status: absent
source: null
tests: []
planned_source: applications/backend/src/example/
---
```

После реализации source указывает существующий каталог, tests — JSON-массив существующих путей от корня. Каталог planned_source может ещё отсутствовать. Описание значений статусов — в [правилах документации](../README.md#поддержка-документации).
