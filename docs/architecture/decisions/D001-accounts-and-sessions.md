# D001: собственные аккаунты и сессии

Статус решения: accepted.

## Контекст

Новая звонилка разрабатывается рядом с существующим Mattermost, но имеет самостоятельную модель доступа. Требуется поддержка нескольких устройств и административного отзыва сессий.

## Решение

Используются собственные аккаунты, вход по логину и паролю, независимые сессии на устройствах до отзыва. Метаданные пользователя передаются через JWT; отдельный endpoint профиля не вводится. Ротация хранит только временный результат, а не полную историю токенов.

## Последствия

Аккаунты Mattermost не переиспользуются. Произвольный исторический refresh token не гарантирует отзыв сессии при logout. Точные сроки, коды, структура хранения, правила повторов и административного восстановления находятся в [Auth](../../backend/modules/auth.md).
