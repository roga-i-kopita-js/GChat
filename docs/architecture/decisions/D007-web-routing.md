# D007: маршрутизация и разделы веб-клиента

Дата: 2026-11-04. Пользователь согласовал React Router, разделение фронтенда на звонки и администрирование и документирование решения.

## Контекст

Веб-клиент переключал разделы локальным состоянием большого `App.tsx`. Административная карточка, поиск и страница списка не имели адреса: обновление страницы и история браузера не восстанавливали выбранное представление. Совместное размещение экрана входа, оболочки, контактов и звонкового интерфейса затрудняло развитие разделов.

Звонок и владение WSS/микрофоном живут дольше отдельной страницы. Перенос жизненного цикла клиента в маршрут звонков привёл бы к его остановке при открытии администрирования.

## Решение

Использовать пакет `react-router` в декларативном режиме с BrowserRouter и вложенными маршрутами. Сохранить Vite и TanStack Query: роутер выбирает страницу и управляет историей, Query отвечает за серверные данные. Версия библиотеки фиксируется манифестом и lock-файлом.

Разделить исходники на композицию приложения `app`, функциональные разделы `features/auth`, `features/calls`, `features/administration` и общие `shared/api`, `shared/ui`. Оболочка отображает дочернюю страницу через Outlet. AuthProvider и CallsProvider находятся выше дерева страниц; единственный звонковый клиент и глобальный входящий вызов принадлежат CallsProvider.

Действующие маршруты, правила доступа, параметры URL, жизненный цикл и границы импортов определены в [веб-контракте](../../web/README.md#маршрутизация-и-структура-исходников).

## Последствия

Прямые ссылки, обновление страницы и история браузера восстанавливают административную карточку и параметры списка. Разделы могут размонтироваться без остановки звонкового клиента. Пароли и состояние отправки административной операции не кодируются в URL.

На хостинге требуется SPA fallback для клиентских адресов с сохранением отдельной обработки `/api` и `/ws`. Проверки маршрутов и сохранения WSS при переходах выполняются браузерными сценариями; работа реального аудиотранспорта проверяется существующими системными тестами.

## Рассмотренные варианты

- Переключатель разделов в React state: не обеспечивает прямые ссылки и историю браузера.
- HashRouter: не требуется при принятом размещении клиента с SPA fallback.
- Data/Framework mode с переносом запросов в роутер: добавляет второй способ загрузки данных рядом с существующим TanStack Query без потребности текущих разделов.
