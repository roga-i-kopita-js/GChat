# D002: отдельный запуск миграций

Статус решения: accepted.

## Контекст

Изменения схемы нужно проверять до развёртывания и применять независимо от запуска HTTP и Redis.

## Решение

Схемы располагаются рядом с бизнес-модулями, SQL и метаданные образуют общую историю в Git. Применение выполняется отдельной командой перед новой версией HTTP-приложения через стандартный мигратор Drizzle. Собственная распределённая блокировка не добавляется; процесс развёртывания обеспечивает последовательный запуск.

## Последствия

HTTP-приложение не меняет схему на старте. История миграций входит в артефакт поставки, уже применённый SQL не редактируется. Команды, расположение файлов, обработка пустой истории и сбоев определены в [инструкции миграций](../../backend/operations/migrations.md).
