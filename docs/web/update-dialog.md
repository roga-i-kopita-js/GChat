# Диалог обновления GChat

Вариант явно согласован пользователем для реализации. Документ владеет требованиями к интерфейсу [обновления Web](README.md#кеш-фронта-и-обновления); действующий порядок безопасной активации и блокировки звонков остаётся у этого контракта. Геометрия сохраняет компактный alert; цвета всех элементов задаёт [общая дизайн-система](../design/winter-theme-task.md).

## Поведение

После готовности установленной новой Web-сборки клиент автоматически открывает модальный диалог в видимой вкладке. Предложение доступно на экране входа и в авторизованных разделах браузерного клиента. Встроенный native-режим не подключается к этому сценарию.

Диалог не открывается поверх другого модального окна, незавершённого входящего/исходящего звонка, разговора или выполняемой команды звонка. Показ откладывается до освобождения интерфейса. Если при открытом предложении поступает звонок, диалог закрывается, освобождает фокус для звонка и снова становится доступен после его завершения. Это автоматическое закрытие не считается выбором «Позже».

Заголовок: «Обновление GChat». Текст: «Доступна новая версия. Обновить приложение сейчас?» Действия в одном ряду: слева «Позже», справа «Обновить».

«Позже», Escape и нажатие на фон закрывают предложение. Оно больше не открывается автоматически до перезагрузки этой вкладки. В существующей полосе уведомлений остаётся компактное сообщение «Доступна новая версия GChat» с действием «Обновить», которое повторно открывает диалог. Закрытие в одной вкладке не скрывает предложение в остальных.

Только явное нажатие «Обновить» внутри диалога запускает существующее безопасное обновление. Диалог закрывается, в полосе уведомлений отображается «Обновление запрошено. GChat перезапустится после завершения звонков во всех окнах». Повторный запуск недоступен. Полоса не блокирует управление звонком и не обещает немедленный перезапуск. Запрос из другой вкладки показывает такое же состояние ожидания без нового модального подтверждения.

Ошибка активации показывается в полосе уведомлений с действием «Повторить», если новая сборка всё ещё доступна. Это действие открывает диалог для нового явного подтверждения. Ошибка подготовки офлайн-режима без готовой новой сборки не вызывает диалог обновления и не получает кнопку активации.

## Строгие визуальные требования

Ориентир — компактный alert Telegram для iOS, соответствующий уже существующему референсу подтверждения звонка GChat. Фиксируется собственное название GChat. Геометрия и состояния ниже служат критериями приёмки, а не общим пожеланием «сделать похоже».

| Элемент          | Требование                                                                                                                                       |
| ---------------- | ------------------------------------------------------------------------------------------------------------------------------------------------ |
| Размещение       | По центру доступной области, с учётом safe area; ширина 300 px, не более ширины экрана минус 32 px                                               |
| Поверхность      | Общая светлая поверхность, радиус 14 px, без цветного бордера, градиента и декоративной иллюстрации                                              |
| Подложка         | Общий токен модальной подложки; фон не получает фокус и нажатия                                                                                  |
| Текстовый блок   | Отступы 20 px сверху и по сторонам, 18 px снизу; текст по центру                                                                                 |
| Заголовок        | Системный шрифт 18 px, вес 600, интерлиньяж 24 px, цвет через токен основного текста                                                             |
| Описание         | Отступ от заголовка 8 px; размер и интерлиньяж через токены основного текста, вес 400, цвет через токен вторичного текста                        |
| Действия         | Два равных столбца; высота минимум 48 px; без промежутка; верхний и центральный разделители 1 px через общий токен разделителя                   |
| Подписи действий | Системный шрифт 16 px; акцент через общий токен; «Позже» — вес 400, «Обновить» — 600                                                             |
| Состояния        | При наведении и нажатии светло-серый фон; видимый focus-visible; без изменения размеров                                                          |
| Адаптация        | Те же пропорции на телефоне и компьютере; при увеличении текста содержимое прокручивается внутри доступной высоты, действия остаются достижимыми |

Крестик, крупная залитая кнопка, логотип, номер сборки и рекламное описание в диалог не добавляются. Сходство принимается по перечисленным размерам, типографике, разделителям и расположению действий.

## Доступность и приёмка

Диалог имеет семантику dialog, доступное имя и описание, удерживает клавиатурный фокус. При открытии фокус получает «Позже»; Enter выполняет только действие сфокусированной кнопки. После закрытия фокус возвращается на доступный исходный элемент; при входящем вызове приоритет получает интерфейс звонка.

Проверяются контрольные размеры 360 × 640, 390 × 844, 430 × 932 и настольный экран, увеличение текста до 200%, клавиатурное управление, длинная ошибка и отсутствие горизонтальной прокрутки. Визуальная приёмка требует снимков обычного состояния и фокуса, с проверкой каждого численного требования таблицы.

Функциональная приёмка включает автоматический показ, «Позже» без активации, повторное открытие из полосы, готовую сборку при открытии вкладки, ожидание завершения звонка/команды, входящий во время диалога, отсутствие наложения на другую модалку, обновление из другой вкладки, ошибку и повтор, отсутствие диалога в native-режиме. Защита звонков проверяется существующими тестами барьера обновления; тест интерфейса не подменяет эту проверку.
