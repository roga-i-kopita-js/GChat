# Выбор аудиоустройства в iOS harness

Расширение [Native Calls](native-calls.md), согласованное пользователем 2026-11-08: заменить переключатель громкой связи выбором доступного аудиоустройства и показывать фактически выбранный выход. Область — отдельный CallHarness, без изменения основного приложения, Web bridge и backend.

Дефект системной кнопки динамика CallKit с 2026-11-10 отложен пользователем за рамки текущего этапа; [граница этапа](native-calls.md#отложенные-дефекты-текущего-этапа). Это решение не подтверждает исправление системного UI или прохождение полного C03.

## Поведение и границы

- При подключённом аудио в harness доступен элемент «Аудиоустройство», открывающий штатный список маршрутов iOS через [AVRoutePickerView](https://developer.apple.com/documentation/avkit/avroutepickerview).
- Состав списка, доступность маршрутов и отметку выбранного устройства определяет iOS для активной голосовой сессии. На физическом iPhone проверяются разговорный динамик, громкая связь и подключённые совместимые AirPods/Bluetooth- или проводная гарнитура. Неподключённые устройства не добавляются вручную; доступность произвольных AirPlay-устройств для двустороннего звонка не обещается.
- Рядом отображается фактический аудиовыход из currentRoute. Имя подключённого аксессуара разрешено показывать в UI; в диагностике остаются только типы портов, без имён и идентификаторов.
- Выбор, системное переключение и подключение/отключение гарнитуры отражаются в UI по событиям аудиосессии. Отдельного сохранённого выбора устройства, принудительного возврата на прежний выход и ручной копии системного списка нет.
- После отключения гарнитуры iOS определяет доступный выход, harness показывает фактический результат. При отсутствии подключённого аудио элемент выбора скрывается.
- Выбор устройства не перенастраивает category/mode, не активирует сессию приложением, не меняет mute и не пересоздаёт PeerConnection. Управление громкостью следует [отдельному контракту](call-volume.md).
- Собственный UI поверх заблокированного экрана CallKit не добавляется. Известный дефект системной кнопки динамика на нём остаётся незакрытым.

## Критерии приёмки

1. На физическом iPhone при активном аудио открывается список устройств; без гарнитуры можно выбрать разговорный динамик и громкую связь.
2. После подключения совместимой гарнитуры она доступна в системном списке. Выбор каждого доступного маршрута подтверждается currentRoute и слышимостью в обе стороны.
3. Отметка в системном списке и подпись harness соответствуют фактическому выходу, в том числе после системного переключения и возврата приложения из фона.
4. При отключении гарнитуры UI отражает системный выход; устаревший выбор не применяется повторно.
5. Переключение не завершает звонок, не меняет mute и не требует переподключения. Системная громкость остаётся регулируемой.
6. После завершения аудио элемент выбора скрывается. В диагностике и сохранённом снимке отсутствуют имена/идентификаторы аксессуаров.

Сборка не заменяет физическую приёмку состава меню и маршрутизации. Недоступная для проверки гарнитура отмечается как not_run/blocked, без объявления полного C03 пройденным.
