# Громкость звонка в iOS harness

Расширение [Native Calls](native-calls.md) для отдельного CallHarness согласовано пользователем 2026-11-08. Основная Capacitor-оболочка и Web bridge в этот объём не входят.

## Поведение и границы

- Во время подключённого аудиозвонка harness показывает подписанный ползунок «Громкость разговора» для текущего системного аудиовыхода.
- Используется видимый штатный [MPVolumeView](https://developer.apple.com/documentation/mediaplayer/mpvolumeview). Его значение управляется iOS и синхронизируется с аппаратными кнопками. Отдельная копия значения громкости в state или UserDefaults не создаётся.
- Пользователь меняет громкость ползунком либо боковыми кнопками iPhone. Приложение не выставляет уровень автоматически при запуске, ответе, переключении динамика или восстановлении звонка.
- Ползунок показывается только при подключённом аудио. Он не меняет чувствительность микрофона, mute, аудиомаршрут, параметры WebRTC или громкость звонка у второго участника.
- На заблокированном экране и в фоне используются аппаратные кнопки iPhone. Собственный элемент поверх системного экрана CallKit не добавляется.
- Для аудиовыходов без регулируемой системной громкости используется штатное поведение MPVolumeView. Числовой процент и отдельный программный регулятор усиления не вводятся.
- Дефект системной кнопки переключения динамика на заблокированном экране остаётся отдельным незакрытым результатом C03.

## Критерии приёмки

1. На физическом iPhone ползунок появляется при подключении аудио и отражает текущую системную громкость.
2. Перемещение ползунка меняет слышимую громкость собеседника; изменение боковыми кнопками отражается в ползунке.
3. Проверка повторяется для разговорного и громкого динамика, выбранных в harness. Переключение маршрута не вызывает принудительной записи прежнего значения приложением.
4. При заблокированном экране боковые кнопки меняют громкость текущего разговора; после возврата ползунок соответствует системе.
5. Изменение громкости не завершает звонок, не меняет mute и не требует переподключения. После завершения ползунок скрывается.

Сборка и проверка Simulator подтверждают только подключение UI. Реальная регулировка и синхронизация принимаются на физическом iPhone.

Пользователь уточнил результат физической проверки: боковые кнопки меняют слышимую громкость разговора, но ползунок не следует за изменениями. Критерий синхронизации не выполнен. [Предложенный контроль без MPVolumeView](call-volume-isolation.md) снят после этого уточнения и не меняет эти требования.
